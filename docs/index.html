mcpguard

Static security linter for Model Context Protocol (MCP) server configurations.

View the sample review report Source on GitHub

What it catches

  • Unpinned npx -y …@latest package installs (supply-chain risk)
  • Hardcoded tokens and keys in env and command-line arguments
  • Broad filesystem roots, shell -c wrappers, and disabled sandbox flags
  • Cleartext http:// remote MCP endpoints and wildcard tool permissions

Zero runtime dependencies. Human, JSON, and SARIF output. GitHub Action ready.

The sample report is generated from a synthetic fixture by a real mcpguard scan — not invented findings. mcpguard inspects configuration files only; it is not a penetration test or source-code audit. See the scope and non-claims.
